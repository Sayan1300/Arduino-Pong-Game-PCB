# Arduino-Pong-Game-PCB
https://youtu.be/TMao8NZsC3g?si=DzRhIndpqjWM7L3b
The final console features a 0.96 inch 128x64 OLED display, a Buzzer for sound, and four Push Buttons for player controls. Finally, the completed Arduino Nano Pong game is tested in three fun modes: 1)One vs. One (2-Player Mode) 2)One vs. CPU (Standard) 3)Hard Level One vs. CPU
